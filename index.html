AI Execution Gateway

AI Execution Gateway es una herramienta local de automatización controlada que conecta flujos autorizados por el usuario con servicios de Google.

Uso de Google

La aplicación utiliza OAuth de Google para acceder, únicamente con autorización del usuario, a archivos creados o seleccionados para el Gateway, hojas de cálculo de control y el envío de notificaciones por Gmail.

El Gateway no vende datos, no los utiliza con fines publicitarios y no comparte información con terceros salvo los proveedores necesarios para prestar las funciones solicitadas.

Control del usuario

El usuario puede revocar el acceso desde la configuración de su cuenta de Google y puede dejar de utilizar la aplicación en cualquier momento.
