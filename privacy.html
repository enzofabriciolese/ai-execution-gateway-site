Política de privacidad

Última actualización: 28 de septiembre de 2026.

Esta política describe cómo AI Execution Gateway trata información cuando el usuario autoriza su integración con servicios de Google.

1. Responsable y alcance

AI Execution Gateway es una herramienta local de automatización controlada mantenida por el titular de la cuenta GitHub enzofabriciolese. Esta política se aplica a la integración OAuth del Gateway con Google.

2. Datos tratados

Según las funciones que el usuario habilite, la aplicación puede tratar identificadores básicos de la cuenta de Google, contenido y metadatos de archivos seleccionados o creados para el Gateway, datos de hojas de cálculo de control y los datos necesarios para preparar y enviar notificaciones por Gmail. La aplicación no solicita contraseñas de Google.

3. Permisos de Google

  • drive.file: acceder solamente a archivos creados por la aplicación o seleccionados explícitamente por el usuario.
  • spreadsheets: leer y actualizar las hojas de cálculo que el usuario usa como plano de control.
  • gmail.send: enviar correos solicitados o notificaciones operativas autorizadas; no permite leer la bandeja de entrada.

4. Finalidad

Los datos se usan exclusivamente para ejecutar flujos autorizados, coordinar trabajos del Gateway, conservar evidencia operativa limitada, prevenir duplicados, diagnosticar errores y enviar las notificaciones solicitadas.

5. Conservación y almacenamiento

La configuración, los tokens OAuth y los registros operativos se almacenan localmente en el equipo del usuario o en los servicios de Google que éste haya elegido. Se conservan sólo mientras sean necesarios para el funcionamiento, la seguridad y la resolución de errores. El usuario puede revocar el acceso en cualquier momento desde la sección de seguridad de su cuenta de Google.

6. Compartición y venta

AI Execution Gateway no vende datos personales, no los utiliza para publicidad y no los comparte con terceros, salvo con Google y con los proveedores técnicos estrictamente necesarios para ejecutar una función solicitada por el usuario o cumplir una obligación legal.

7. Uso limitado de datos de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las APIs de Google se ajustan a la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de Uso Limitado.

8. Seguridad

El Gateway aplica autorización explícita, alcance mínimo de permisos, almacenamiento local de credenciales, controles de idempotencia y barreras para operaciones sensibles. Ningún sistema puede garantizar seguridad absoluta; por ello se recomienda revocar el acceso si se sospecha un uso no autorizado.

9. Derechos, eliminación y contacto

El usuario puede dejar de usar la aplicación, revocar OAuth y eliminar los archivos o registros que controla. Para consultas de privacidad o solicitudes de eliminación, puede abrir una incidencia en el repositorio público de soporte. No incluya credenciales, tokens ni información sensible en una incidencia pública.

10. Cambios

Las modificaciones materiales de esta política se publicarán en esta misma página y se indicará una nueva fecha de actualización.
